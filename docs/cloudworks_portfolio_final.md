# クラウドワークス用ポートフォリオ入力文

## 1. タイトル

売上データ自動集計・月末売上管理ツール

## 2. 概要文

CSV / Excelの売上データを読み込み、月末確認用のExcelレポートを自動作成するPython業務改善ツールです。商品別、カテゴリ別、日別、月別の売上集計に対応し、月末サマリー、前月比較、未分類データ、エラー行一覧をまとめて出力できます。GUIとCLIの両方から実行できるため、画面操作で使いたい場合と定型処理として実行したい場合のどちらにも対応しやすい構成です。手作業による集計や転記ミス、確認漏れを減らすことを目的に、サンプルデータと操作マニュアルを含めてGitHubで公開しています。

## 5. 工夫した点

現場で扱いやすいように、CSV / Excelの両方を入力形式として使える構成にしました。日本語列名にも対応しやすいよう、列名マッピングを用意し、データ形式の違いで処理が止まりにくい設計にしています。

月末確認で必要になりやすい売上合計、明細件数、平均単価などを月末サマリーとしてまとめ、前月データがある場合は前月比較も出力できるようにしました。未分類データやエラー行一覧もExcelレポート内に出力し、確認漏れを防ぎやすくしています。

利用方法はGUIとCLIの両方に対応しました。画面から操作したい場合はTkinter GUIを使い、定型処理や確認用途ではCLIから実行できます。また、pytestで主要機能を確認できるようにし、READMEにはスクリーンショットを追加して、動作イメージが伝わりやすい形に整えました。GitHub公開時にはサンプルデータのみを含め、実データや個人情報を含めない構成にしています。

## 6. 業務改善としての価値

毎月発生する売上集計作業を効率化し、Excelでの手作業による転記ミスや集計ミスを減らすことを意識して作成しました。月末サマリー、前月比較、未分類データ、エラー行一覧を同じ手順で出力できるため、月末確認作業を標準化しやすくなります。

担当者以外でも同じ条件で集計しやすく、確認すべきデータも見つけやすい構成です。出力はExcelレポートのため、Excel中心の業務現場でも導入後の運用イメージを持ちやすい点を重視しています。
