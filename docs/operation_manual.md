# 売上データ自動集計・月末売上管理ツール 操作マニュアル

## 1. このツールでできること

- 売上データを自動集計できます。
- 月末売上確認に必要なExcelレポートを作成できます。
- 商品別・カテゴリ別の売上ランキングを確認できます。
- 日別・月別の売上推移を確認できます。
- 未分類データやエラー行を確認できます。
- CLIとGUIのどちらからでも実行できます。

## 2. 初回セットアップ

Windows PowerShellを開き、プロジェクトフォルダで次のコマンドを実行します。

```powershell
powershell -ExecutionPolicy Bypass -File .\setup.ps1
```

このスクリプトは、Python仮想環境 `.venv` を作成し、`requirements.txt` のライブラリをインストールします。

GUIでドラッグ＆ドロップを使う場合は、任意依存も入れます。

```powershell
powershell -ExecutionPolicy Bypass -File .\setup.ps1 -InstallDragDrop
```

古いExcel形式 `.xls` を読み込む場合は、環境によって `xlrd` が必要です。

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-optional.txt
```

## 3. 入力データの準備

売上データは `data/input` に置きます。

対応形式:

- `.csv`
- `.xlsx`
- `.xls`

推奨は `.csv` または `.xlsx` です。`.xls` は古い形式のため、可能であれば `.xlsx` に保存し直してください。

必要な列の例:

| 列名 | 内容 |
| --- | --- |
| `date` | 売上日。例: `2026-04-01` |
| `product` | 商品名 |
| `category` | カテゴリ |
| `quantity` | 数量 |
| `unit_price` | 単価 |

日本語列名の例:

- 日付
- 商品名
- カテゴリ
- 数量
- 単価

`amount` は必須ではありません。数量と単価から自動計算します。

### サンプルデータ

`data/input` には、架空の小売・雑貨店を想定したサンプル売上データがあります。
`sales_2026_03.csv` と `sales_2026_04.csv`、同内容の `sample_sales_2026_03.xlsx` と `sample_sales_2026_04.xlsx` を用意しています。
2026年4月を対象月として実行すると、2026年3月との前月比較を確認できます。
実会社名・個人情報・実売上データは含めていません。

## 4. GUIでの使い方

GUIは次のコマンドで起動します。

```powershell
.\.venv\Scripts\python.exe gui.py
```

主な入力項目:

- 入力フォルダ: 売上CSVまたはExcelを置いた場所を指定します。
- 出力フォルダ: Excelレポートの保存先を指定します。
- 対象月: `2026-04` のように入力します。
- 開始日・終了日: 任意の期間を指定したい場合に使います。
- 商品名で絞り込み: 特定の商品だけを集計したい場合に入力します。
- カテゴリで絞り込み: 特定カテゴリだけを集計したい場合に入力します。
- 読み込みファイル名パターン: 例 `sales_*.csv`。同じ名前規則のExcelも読み込み対象になります。
- データをプレビュー: 読み込みデータを確認します。
- 集計プレビュー: 商品別・カテゴリ別・日別の集計を確認します。
- Excelレポートを作成: 月末確認用のExcelレポートを作成します。

実行タブは画面サイズに合わせて縦スクロールできます。画面下部の結果・エラー表示や操作ボタンが見切れる場合は、ウィンドウを最大化するか、マウスホイールで実行タブをスクロールしてください。
チェック項目はチェックマークでON/OFFを切り替えます。プリセット欄は保存済み設定を選ぶ欄です。入力欄の右側にある説明文を参考に設定してください。

チェック項目:

- 商品別・カテゴリ別集計を出力
- 月別推移を出力
- グラフを出力
- 検証のみ実行
- 完了時に通知音を鳴らす

対象月と開始日・終了日は同時に指定できません。どちらか一方を使ってください。

基本操作手順:

1. 入力フォルダまたは売上ファイルを選択します。
2. 出力フォルダを確認します。
3. 対象月を `2026-04` のように指定します。
4. 「データをプレビュー」で読み込み内容を確認します。
5. 必要に応じて「集計プレビュー」で集計結果を確認します。
6. 「Excelレポートを作成」を押してレポートを出力します。

レポート作成後は、画面下部に出力ファイル、売上合計、明細件数、数量合計、平均単価、前月売上、前月比、未分類データ件数、エラー行件数が表示されます。

作成後の確認:

- Excelレポートを開く: 最新の作成済みExcelレポートを開きます。
- 出力フォルダを開く: 現在指定している保存先フォルダをエクスプローラーで開きます。

まだレポートを作成していない場合は、「Excelレポートを作成」を先に実行してください。

### 作成済みレポートの見方

「作成済みレポート」タブでは、出力フォルダ内の作成済みExcelレポートを確認できます。  
まだレポートを作成していない場合は、空状態の案内が表示されます。

- 履歴を更新: 出力フォルダのレポート一覧を再読み込みします。
- 詳細: 選択したレポートのファイル名、保存場所、サイズ、更新日時を確認します。
- 選択したレポートを開く: 選択したExcelレポートを開きます。

レポートが開けない場合は、ファイルが削除または移動されていないか確認してください。

### 実行履歴・詳細ログの見方

「実行履歴」タブでは、実行日時、対象期間、明細件数、出力ファイル、エラー内容を確認できます。  
「詳細ログ」タブでは、実行ログや監査ログの内容を確認できます。レポート作成時に問題が起きた場合は、この2つのタブを確認してください。

画面上部のタブ名は「実行」「エラー確認」「作成済みレポート」「実行履歴」「詳細ログ」です。選択中のタブは色で分かるようになっています。

### エラー確認タブの使い方

「エラー確認」タブでは、Excelレポートを開かなくても入力データの検証エラーを確認できます。  
エラー一覧は縦・横スクロールに対応しているため、元ファイル名、行番号、エラー内容、修正方法を画面上で確認できます。

1. 実行タブで入力フォルダ、対象月、列名設定を確認します。
2. 画面上部の「エラー確認」タブを開きます。
3. 「入力データを検証」を押します。
4. エラーがある場合は、元ファイル名、行番号、エラー内容、修正方法を確認します。
5. CSV / Excelを修正して、もう一度検証またはレポート作成を実行します。

表示される主な列:

- 元ファイル名
- 行番号
- エラー内容
- 修正方法
- 日付
- 商品名
- カテゴリ
- 数量
- 単価
- 金額

エラーがない場合は「検証エラーはありません。現在の入力データは正常に読み込めます。」と表示されます。  
検証エラーがある場合は「エラーCSVを開く」からエラー一覧CSVを確認できます。

### 列名マッピングの設定

会社や担当者によってCSV / Excelの列名が違う場合は、GUIで列名マッピングを設定できます。

1. 実行タブで入力フォルダまたは売上ファイルを指定します。
2. 「列名設定を開く」を押します。
3. 「入力ファイルの列名を読み取る」を押します。
4. 標準項目ごとに、入力ファイルの列名を選択します。
5. 「列名設定を保存」を押します。

設定例:

| 標準項目 | 入力ファイルの列名 |
| --- | --- |
| 日付 | 売上日 |
| 商品名 | 品名 |
| カテゴリ | 商品分類 |
| 数量 | 販売数 |
| 単価 | 販売単価 |
| 金額 | 売上金額 |

よくある列名は自動推定されます。

- 日付: 日付、売上日、販売日、取引日
- 商品名: 商品名、商品、品名
- カテゴリ: カテゴリ、分類、商品分類
- 数量: 数量、個数、販売数
- 単価: 単価、販売単価
- 金額: 金額、売上金額、税込金額、売上

保存した列名設定は、次回のデータプレビュー、集計プレビュー、Excelレポート作成に反映されます。  
列名不足エラーが出た場合は、この画面で標準項目と入力ファイルの列名が対応しているか確認してください。

## 5. EXE版での使い方

配布版を使う場合は、`SalesReportManager` フォルダを展開し、フォルダ内の `SalesReportManager.exe` をダブルクリックして起動します。  
Pythonや仮想環境のコマンドを直接実行しなくてもGUIを開けます。

EXE版はフォルダごと使用してください。`SalesReportManager.exe` だけを別の場所へ移動すると、`_internal` 内のDLLやライブラリが見つからず起動できない場合があります。

EXE版でも、入力フォルダ・出力フォルダ・対象月の指定は通常版と同じです。

1. `SalesReportManager.exe` を起動します。
2. 入力フォルダまたは売上ファイルを選択します。
3. 出力フォルダを確認します。
4. 対象月を `2026-04` のように入力します。
5. データをプレビューします。
6. Excelレポートを作成します。
7. 「Excelレポートを開く」で作成結果を確認します。

通常版はPython環境から `gui.py` を起動する開発・確認向けの使い方です。EXE版は、Python環境に詳しくない利用者へ配布しやすい形式です。  
エラーが出た場合は、通常版と同じように「エラー確認」タブでエラー内容と修正方法を確認してください。

```powershell
.\.venv\Scripts\python.exe main.py --month 2026-04 --all-summaries --monthly-trend --charts

.\.venv\Scripts\python.exe main.py --config config.example.json --preset april_report
```

## 7. 出力されるExcelレポートの見方

Excelレポートには次のシートが出力されます。

1. 月末サマリー
2. 前月比較
3. 詳細データ
4. 商品別集計
5. カテゴリ別集計
6. 日別推移
7. 月別推移
8. 未分類データ
9. エラー行一覧
10. 実行条件

各シートの内容:

- 月末サマリー: 月末確認に必要な主要指標を一覧表示します。
- 前月比較: 当月と前月の売上・件数・平均単価などを比較します。
- 詳細データ: 読み込んだ明細データと計算金額を確認できます。
- 商品別集計: 商品別の売上、件数、数量、平均単価、順位を確認できます。
- カテゴリ別集計: カテゴリ別の売上、件数、数量、平均単価、順位を確認できます。
- 日別推移: 日ごとの売上推移を確認できます。
- 月別推移: 月ごとの売上推移を確認できます。
- 未分類データ: 商品名やカテゴリに確認が必要な明細を表示します。
- エラー行一覧: 検証エラーの有無を確認します。
- 実行条件: 実行時に指定した条件を記録します。

## 8. 月末サマリーの見方

主な項目:

- 対象月: 集計対象の月です。
- 集計期間: 集計対象となった日付範囲です。
- 売上合計: 対象期間の売上合計です。
- 明細件数: 対象となった売上明細の件数です。
- 数量合計: 数量の合計です。
- 平均単価: 売上合計を数量合計で割った値です。
- 対象日数: 売上データが存在する日数です。
- 商品数: 対象期間に登場した商品数です。
- カテゴリ数: 対象期間に登場したカテゴリ数です。
- 売上トップ商品: 売上合計が最も大きい商品です。
- 売上トップカテゴリ: 売上合計が最も大きいカテゴリです。
- 未分類データ件数: 確認が必要な未分類データの件数です。
- エラー行件数: 検証エラー行の件数です。
- 確認が必要な件数: 未分類データ件数とエラー行件数の合計です。

## 9. 前月比較の見方

- 当月: 対象月の値です。
- 前月: 対象月の前月の値です。
- 差分: 当月から前月を引いた値です。
- 増減率: 差分を前月値で割った値です。
- 前月データなし: 前月に該当データがない状態です。
- 比較不可: 前月が0または前月データがないため、増減率を計算しない状態です。

## 10. 未分類データ・エラー行一覧の見方

未分類データとして確認される例:

- 商品名が空欄
- カテゴリが空欄
- 商品名が未設定
- カテゴリが未分類
- カテゴリがその他

`その他` はエラーではありませんが、月末確認時に分類を見直す対象として表示します。

エラー行一覧で確認できる内容:

- 日付不正
- 数量不正
- 単価不正
- 金額不正
- 必須列不足

エラー行一覧には「エラー内容」と「修正方法」が表示されます。  
金額は数量と単価から自動計算しますが、入力データに金額列がある場合は、文字やマイナス値が入っていないか確認します。

## 11. よくあるエラーと対処法

### Pythonが見つからない

Pythonをインストールし、PowerShellで `python --version` が動くか確認してください。

### 仮想環境がない

次を実行してください。

```powershell
powershell -ExecutionPolicy Bypass -File .\setup.ps1
```

### pandasがない / openpyxlがない

依存ライブラリを再インストールしてください。

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### xlsが読み込めない

古いExcel形式（`.xls`）を読み込むには追加ライブラリが必要です。  
可能であれば、Excelで `.xlsx` 形式に保存し直してから読み込んでください。  
`.xls` のまま使う場合は、任意依存を入れてください。

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-optional.txt
```

### CSVが文字化けする

UTF-8、UTF-8 BOM、CP932を順に試して読み込みます。解決しない場合は、Excelで開いて `.xlsx` に保存し直してください。

### 対象月のデータがない

対象月を指定してデータが0件になる場合は、次を確認してください。

- 対象月が正しいか
- CSV / Excelの日付列が正しいか
- `data/input` に対象月のファイルがあるか
- 読み込みファイル名パターンが正しいか

例:

- 対象月: `2026-04`
- 読み込みファイル名パターン: `sales_*.csv`

### 開始日が終了日より後になっている

開始日と終了日の指定を見直してください。

修正例:

- 開始日: `2026-04-01`
- 終了日: `2026-04-30`

### 列名が足りない

CSVまたはExcelの1行目に必要な列名があるか確認してください。

必要な列の例:

- 日付
- 商品名
- カテゴリ
- 数量
- 単価
- 金額

日本語列名にも対応しています。列名が異なる場合は、列名マッピングを設定してください。

### 日付形式が読み取れない

日付列に日付として読み取れない値が入っている場合に発生します。

修正例:

- `2026-04-01`
- `2026/04/01`

### 数量・単価・金額が読み取れない

数量、単価、金額に文字やマイナス値が入っていないか確認してください。

修正例:

- 数量: `1`、`2`、`10`
- 単価: `100`、`1200`
- 金額: `1000`、`2500`

金額は数量と単価から自動計算されます。入力データに金額列がある場合も、数量と単価を正しく入力してください。

### 読み込み対象ファイルが見つからない

次を確認してください。

- 入力フォルダが正しいか
- `data/input` にCSVまたはExcelファイルがあるか
- 読み込みファイル名パターンが正しいか

例:

- `sales_*.csv`
- `sales_*.xlsx`

`sample_` で始まるファイルはサンプルとして除外されます。

### Excelレポートが開けない

出力中にExcelファイルを開いていないか確認してください。
作成済みレポートや最新レポートから開けない場合は、ファイルが削除または移動されていないか確認してください。

### ファイルが使用中で上書きできない

Excelで対象ファイルを閉じてから再実行してください。

## GUIの作成済みレポート・実行履歴・詳細ログ

### 作成済みレポート

「作成済みレポート」タブでは、作成したExcelレポートを一覧で確認できます。
表には作成日時、対象月、ファイル名、種類、サイズ、保存先が表示されます。最新のレポートほど上に表示されます。

レポートを開く場合は、一覧から対象行を選択して「選択したレポートを開く」を押します。保存先を確認したい場合は「保存先フォルダを開く」を押します。レポートが表示されない場合は、実行タブでExcelレポートを作成してください。

### 実行履歴

「実行履歴」タブでは、過去の実行結果やエラー概要を確認できます。レポート作成時に問題が起きた場合は、まずこの画面で状態、期間、明細件数、集計件数、警告数、出力先、エラー内容を確認します。

必要に応じて「履歴をCSV出力」「要約CSVを作成」「月別要約CSVを作成」「履歴をバックアップ」を使用できます。出力先やエラー内容が長い場合は、一覧下部の横スクロールで右端まで確認してください。

### 詳細ログ

通常は「実行履歴」タブや「エラー確認」タブを確認します。詳しい原因を調べたい場合に「詳細ログ」タブを使用してください。

「詳細ログ」タブでは、実行ログや内部ログを表形式で確認できます。「エラーのみ表示」を押すと、error、exception、エラー、失敗、validation_error を含むログに絞り込めます。「全件表示」で全ログに戻せます。

ログ行を選択すると、JSONなどの詳細情報が下部の「選択したログの詳細」に表示されます。ログファイルを直接確認したい場合は「ログフォルダを開く」を押してください。
- サンプルデータは架空データを使用し、実会社名、個人名、住所、電話番号、メールアドレス、認証情報は含めないでください。
- README用スクリーンショットを更新する場合は、[スクリーンショット撮影ガイド](screenshot_guide.md) を参照してください。
