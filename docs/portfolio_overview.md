# ポートフォリオ説明文

## ツール名

Sales Report Manager  
売上データ自動集計・月末売上管理ツール

## 概要

CSV / Excelの売上データを読み込み、月末確認に必要な集計レポートを自動作成するPython業務改善ツールです。商品別・カテゴリ別ランキング、日別・月別推移、月末サマリー、前月比較、未分類データ確認まで一括でExcel出力できます。

## 作成目的

現場で毎月発生する売上集計、月末確認、前月比較、データ不備チェックを効率化するために作成しました。Excelでの手作業集計を減らし、確認漏れや集計ミスを防ぐことを目的としています。

## 解決できる課題

- 毎月の売上集計に時間がかかる
- 商品別・カテゴリ別の集計表を手作業で作っている
- 月末サマリーや前月比較の作成に手間がかかる
- 未分類データや入力エラーを見落としやすい
- CSVの文字化けや列名違いで処理が止まりやすい
- GUIとCLIの両方で使える業務ツールがほしい

## 主な機能

- CSV / Excel入力対応
- UTF-8 / UTF-8 BOM / CP932のCSV読み込み
- 列名マッピング
- 対象月・期間・商品・カテゴリ指定
- 商品別・カテゴリ別集計
- 商品別・カテゴリ別ランキング
- 日別・月別売上推移
- 月末サマリー
- 前月比較
- 未分類データ一覧
- エラー行一覧
- Excelレポート出力
- Excelグラフ出力
- GUI / CLI 両対応
- pytestによるテスト

## 使用技術

- Python
- pandas
- openpyxl
- Tkinter
- pytest
- PowerShell

## 工夫した点

- CSV / Excel両対応にし、現場で使われやすい入力形式に対応しました。
- UTF-8、UTF-8 BOM、CP932を考慮し、日本語CSVの文字化けに配慮しました。
- 日本語列名にも対応しやすい列名マッピングを用意しました。
- 月末サマリーで、売上合計、件数、数量合計、平均単価、トップ商品、トップカテゴリを確認できるようにしました。
- 前月比較シートを用意し、月次報告に使いやすくしました。
- 未分類データ・エラー行一覧をExcel内に出し、確認漏れを防げる構成にしました。
- GUI / CLI 両対応にし、初心者にも自動実行にも使いやすい形にしました。
- pytestで主要処理をテストし、既存機能を壊しにくい構成にしました。
- GitHub公開を意識し、サンプルデータと出力データを分離しました。

## 業務改善としての価値

月末の売上集計、前月比較、未分類データ確認を自動化することで、手作業の集計時間を削減できます。  
また、確認が必要なデータをExcelレポート内にまとめて表示するため、分類漏れや入力ミスに気づきやすくなります。  
月末処理の手順を標準化し、担当者ごとの作業ばらつきを減らせる点も業務改善としての価値です。
