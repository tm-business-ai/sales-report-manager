# 売上データ自動集計・月末売上管理ツール 簡易起動ガイド

## 1. 起動方法

SalesReportManager フォルダを任意の場所に展開し、フォルダ内の SalesReportManager.exe をダブルクリックしてください。

このツールは SalesReportManager フォルダごと使用してください。SalesReportManager.exe だけを別の場所へ移動すると、必要なファイルが見つからず起動できない場合があります。

## 2. 基本操作

1. 入力フォルダまたは売上ファイルを選択
2. 出力フォルダを確認
3. 対象月を入力
4. データをプレビュー
5. Excelレポートを作成
6. Excelレポートを開く

## 3. 入力データ

CSVまたはExcelを data/input に入れてください。

対応形式:
- .csv
- .xlsx
- .xls

## 4. 出力先

作成されたExcelレポートは data/output に保存されます。

## 5. 困ったとき

- エラー確認タブを見る
- 操作マニュアルを見る
- 入力データの列名、日付、数量、単価、金額を確認する

詳しい操作方法は、配布フォルダ内の docs\operation_manual.pdf を確認してください。
PDFには画像付きの操作説明があります。

## 6. 注意事項

実データ、個人情報、認証情報はサンプルフォルダに入れたまま公開しないでください。
配布や移動を行う場合は、SalesReportManager フォルダ全体をZIP化またはコピーしてください。
EXE単体ではなく、SalesReportManager フォルダごと使用してください。
